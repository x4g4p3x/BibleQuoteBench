Execution and evidence

The CLI selected Grok 4.7 256K Extra High, with Fast = false. The successful launch took 439.25 seconds and reported 11,099 input tokens, 5,214 output tokens and 320,000 cache-read tokens. These are launch-level usage figures; no per-case token usage or price was verified.

No paid provider API calls were made. Cursor account usage was consumed. Local permissions denied web, shell and file tools; the transcript showed only benchmark calls and their schema discovery. The evidence remains interactive_mcp, with an unresolved service model identity.

Raw thinking, account metadata, session identifiers and local paths remain private. The public bundle contains the submitted answers, the reference subset, scores and sanitized provenance. See the report for the initial guard interruption, audit details, digest scope and reproduction instructions.
