Method, provenance, and limits

    Reports show precomputed analysis values. Switching tracks never pools their cases or scores. This file works offline and makes no network requests.

    Scoring and uncertainty terms

    Exact text (ExactText) preserves wording, case, punctuation, and whitespace after scorer normalization. Words only (ExactWords) preserves Unicode word identity and case while ignoring punctuation. A percentage-point difference subtracts one rate from the other; it is not a relative percentage change.

    Confidence intervals resample references within reference groups (strata). Translations and repeated attempts for each reference stay together. Paired intervals compare the same cases and are exploratory, with no adjustment for multiple comparisons.
